# 앱스토어 출시 체크리스트

## 출시 전에 정할 것
- [ ] 앱 이름 (지금은 가칭 `tripnote`)
- [ ] 번들 ID (`app.json` 의 `ios.bundleIdentifier`, 지금은 자리표시자 `com.example.tripnote`). 한 번 출시하면 바꿀 수 없습니다. 예: `com.<내이름>.<앱이름>`
- [ ] 앱 아이콘과 시작 화면 (`assets/` — 지금은 엑스포 기본 그림)

## 계정
- [ ] 애플 개발자 프로그램 가입 (연 99달러) — https://developer.apple.com/programs
- [ ] 앱스토어 커넥트에서 새 앱 등록 (이름, 번들 ID, 기본 언어 한국어)

## 빌드와 테스트
- [ ] 제출용 빌드: `npx eas-cli@latest build --profile production --platform ios`
- [ ] 업로드: `npx eas-cli@latest submit --platform ios`
- [ ] 테스트플라이트로 본인 폰에 설치해 실제 여행 하루치를 써보기

## 스토어 등록 정보
- [ ] 스크린샷 (6.9인치 아이폰 기준 필수)
- [ ] 앱 설명, 키워드, 카테고리(여행)
- [ ] 개인정보 처리방침 URL — 필수. "모든 데이터는 기기에만 저장되며, 장소 검색어와 좌표가 구글 지도 서비스로 전송된다"는 내용을 담습니다.
- [ ] 앱 개인정보 항목: 위치(앱 기능용, 추적 아님), 사진(기기에만 저장)

## 심사에서 자주 걸리는 부분
- [ ] **백그라운드 위치**: 심사 메모에 "일정에 등록한 장소에 도착한 시간을 자동 기록하는 기능에만 사용하며, 위치를 서버로 보내지 않는다"고 적습니다. 권한을 거부해도 앱이 정상 동작해야 합니다(수동 "도착" 버튼으로 동작함).
- [ ] **구글 출처 표기**: 지도 왼쪽 아래 Google 로고와 장소 정보의 "장소 정보 제공: Google" 문구를 가리지 않습니다.
- [ ] 심사자가 로그인 없이 모든 기능을 쓸 수 있습니다(회원가입 없음).

## 사용자가 늘기 전에
- [ ] 구글 API 키를 앱 밖으로 옮기기. 지금은 키가 앱 안에 들어 있어 추출될 수 있습니다. 본인과 지인 테스트 단계에서는 API 제한과 일일 한도로 충분하지만, 불특정 다수에게 공개하기 전에는 키를 숨기는 작은 중계 서버를 둡니다.
- [ ] 구글 클라우드 결제 알림(예산 알림) 설정
